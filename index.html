2025 · Academic project

Integrated Loan Processing and Client Monitoring System

A web-based lending system for E-Z Lending Solutions that simplifies loan applications, payment monitoring, client management, and financial reporting. It helps reduce manual work and improve accuracy and efficiency.

Highlights

Online Loan Application

Clients apply for a loan online by completing their profile and loan details in the system, then follow the status of the application without visiting the office.

Automated Loan Computation

The system computes loan amounts and repayment details automatically, so staff and clients get consistent figures without manual calculation.

OCR Profile Verification

Optical character recognition reads details from submitted documents to help verify a client’s profile, which cuts down on manual encoding and checking.

Automated Financial Reporting

Reports on loans and payments are generated by the system, replacing manual spreadsheets and making records faster to review and more accurate.

Role-Based Access

Each type of user sees only the features that fit their role, which keeps client and financial data protected.

My role

  • Designed the user interface (UI) of the system.
  • Created the visual design of the system.
  • Designed system models, including the Data Flow Diagram (DFD).
  • Tested system modules and reported defects for the team to fix.
  • Wrote and debugged code for system modules.
